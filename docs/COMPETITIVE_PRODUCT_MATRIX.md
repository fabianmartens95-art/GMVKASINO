# GMVKASINO Competitive Product Matrix V1

Status: Product benchmark framework  
Effective: 2026-09-18  
Parent: `docs/PRODUCT_DELIVERY_OS.md`

## Purpose

Benchmark comparable casino/player and operations experiences systematically without blindly copying competitors or weakening GMVKASINO integrity/compliance standards.

## Decision rule

A competitor feature does not automatically become a roadmap item.

Create work only when:
1. a concrete user/operations problem is identified,
2. the pattern is compatible with the authoritative backend and security model,
3. compliance/player-safety implications are understood,
4. the capability fits the active or future Casino Product Wave.

## Evidence fields

For every benchmark entry record:
- product/operator
- date observed
- market/jurisdiction context
- user surface
- observed behavior
- evidence/source
- GMVKASINO gap
- Adopt / Adapt / Reject / Defer
- target Product Wave
- linked issue if implementation is approved

## Maintenance

Refresh the matrix before major Player UX, Cashier, Operations or Launch-readiness decisions. Time-sensitive claims must be revalidated before relying on them.
